# Les musiques des événements du ciel

Dépose ici les morceaux joués quand survient un événement rare — supernova,
comète bleue, trou noir. **Un fichier déposé suffit** : rien à déclarer nulle
part, le dossier est ramassé à la construction (`import.meta.glob` dans
`../musiqueEvenement.ts`), et un morceau est **tiré au sort à chaque
événement**.

- Extensions reconnues : `.mp3`, `.ogg`, `.m4a`, `.wav`.
- Le nom n'a aucune importance.
- Dossier vide : les événements sont muets, et l'onglet Graphisme des
  paramètres le dit en toutes lettres.

Un morceau choisi par l'utilisateur depuis ses propres fichiers prend le pas sur
tout ce dossier.

## Droits

N'y mets que des morceaux que l'application a le droit de distribuer — les
pistes d'ambiance viennent de Pixabay, dont la licence n'exige aucune
attribution. Les crédits se tiennent dans `../../ambient/tracks.ts` ; ajoute les
tiens ici.
